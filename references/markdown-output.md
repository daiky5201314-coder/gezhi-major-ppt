# Markdown输出与对应规范

## 最终文件

默认生成两个独立文件：

1. `<主题>-PPT内容稿.md`
2. `<主题>-逐字讲解稿.md`

文件名使用用户确认的官方专业名称。两份文件必须拥有相同页数、页码和页面标题。

## 文件一：PPT内容稿

```markdown
# 《××》PPT内容稿

## 课程信息

- 课程类型：专业大类 / 单专业
- 专业名称：
- 官方目录版本：
- 资料核验日期：
- 预计页数：

---

## 第1页｜页面标题

### 本页核心结论

一句话结论。

### PPT展示内容

1. 要点一
2. 要点二
3. 要点三

### 建议呈现形式

说明使用标题页、关系图、对比表、流程图、岗位地图或院校分层图。

### 资料依据

- [来源名称](链接)，发布或核验时间。
```

PPT展示内容只写适合上屏的文字。复杂信息优先用表格、分区卡片或关系图，避免大段文章。

## 文件二：逐字讲解稿

```markdown
# 《××》逐字讲解稿

## 使用说明

- 与《××》PPT内容稿逐页对应。
- 教师可以直接照读，并可根据课堂情况删减案例。

---

## 第1页｜与PPT完全相同的页面标题

### 对应的PPT要点

1. 要点一
2. 要点二
3. 要点三

### 逐字讲解

本页标题导入。

第一，对应要点一的讲解。

第二，对应要点二的讲解。

第三，对应要点三的讲解。

本页小结。

过渡到下一页。
```

“对应的PPT要点”必须从PPT内容稿原样复制，作为校对锚点；逐字讲解按相同编号和顺序展开。

## 一致性规则

- 页数一致。
- 页码一致。
- 标题逐字一致。
- 要点数量和顺序一致。
- PPT中的表格维度必须在逐字稿中解释。
- PPT中的数据必须在逐字稿中说明意义和口径。
- 逐字稿可以增加解释、类比和场景，不得增加新的页面主题。
- 逐字稿不得提前详细讲下一页。
- 封面、目录也要有对应讲解，但保持简短。
- 最后一页不写“下一页过渡”，改为课程收束语。

## 自动校对

| 检查项 | 结果 |
|---|---|
| 两个文件页数相同 | 通过/修正 |
| 每一页标题完全相同 | 通过/修正 |
| 每一项PPT要点都有讲解 | 通过/修正 |
| 逐字稿顺序与PPT一致 | 通过/修正 |
| 没有跨页重复展开 | 通过/修正 |
| 关键事实有来源和年份 | 通过/修正 |

检查表用于内部校对，除非用户要求，不必写入最终文件。
