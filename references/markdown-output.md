# Markdown输出与对应规范

## 最终文件

默认生成三个独立文件：

1. `<主题>-PPT内容稿.md`
2. `<主题>-逐字讲解稿.md`
3. `<主题>-资料来源与核验表.md`

文件名使用用户确认的官方专业名称。前两个文件必须拥有相同页数、页码和页面标题。

## 文件一：PPT内容稿

PPT内容稿将直接交给PPT生成AI。它只包含最终需要显示在页面上的文字。

```markdown
# 第1页｜《××专业全景解析》

××类（专业代码）

从专业差异看大学学习、就业岗位、升学与院校选择

---

# 第2页｜本课程讲什么

* 这个专业大类到底是干什么的
* 包含哪些细分专业，重点专业有什么区别
* 大学阶段主要学什么，学习门槛在哪里
* 本科毕业能去哪些行业、单位和岗位
* 是否需要读研，考公考编机会多不多
* 哪些院校值得关注，选择时要避开什么风险

---

# 第3页｜第一部分：热门背后，更要看清真实门槛

在看具体专业之前，先判断这个大类解决什么问题，以及普通学生面对的就业、学历和平台门槛。

---

# 第4页｜认识××类，先记住这5个判断

| 判断项 | 直接结论 |
|---|---|
| 核心定位 | …… |
| 本科就业 | …… |
| 读研必要性 | …… |
| 平台依赖 | …… |
| 最大风险 | …… |

一句话记住：

> ……
```

允许出现的内容：

- 可直接上屏的短段落、列表、编号和表格
- 为观众阅读服务的“小标题”“核心结论”“一句话记住”
- 页面本身需要呈现的专业代码、年份、数据口径或必要注释
- 与目录一一对应的模块过渡页

禁止出现的内容：

- `本页核心结论`
- `PPT展示内容`
- `建议呈现形式`
- `资料依据`
- `课程信息`
- 配色、布局、图标、动画等制作指令
- 内部校对说明、研究过程和引用链接

这些词只有在确实要成为页面可见文字时才可使用，不能作为每页固定模板标签。页面标题统一使用一级标题 `# 第X页｜标题`，页面之间统一使用 `---`。

过渡页标题使用“模块序号+判断式标题”，正文只包含一句核心问题。标题应凝练、正式、有对比，但不使用夸张措辞。不要复制目录，不要罗列后续页面标题，不要为了视觉效果重复专业名单或前文结论。

推荐标题结构：

```markdown
# 第X页｜第一部分：热门背后，更要看清真实门槛

# 第X页｜第二部分：专业名称虽多，关键要看技术主线

# 第X页｜第三部分：大学学什么，决定未来能做什么
```

以上是句式示例，不得对所有专业机械照抄。标题必须根据当前大类或单专业的真实矛盾重新组织。

## 文件二：逐字讲解稿

逐字稿不是PPT内容的复制件。它在相同页码和标题下直接给出老师可以照读的口语。

```markdown
# 第1页｜《××专业全景解析》

今天我们讲××类。先不要急着看专业名字，我们会从它解决什么问题开始，再讲大学学什么、本科能做什么、哪些方向更需要读研，以及学校平台到底有多重要。

---

# 第2页｜本课程讲什么

这门课按六个问题展开。第一，我们先把这个大类的定位说清楚。第二，再把细分专业分组……

---
```

逐字稿不得出现：

- `使用说明`
- `对应的PPT要点`
- `逐字讲解`
- PPT要点的整段重复粘贴
- 讲给制作者看的校对或排版说明

讲解必须覆盖PPT上的全部信息并保持同序，但要把列表和表格转化为自然口语，不机械朗读标点和表头。

## 文件三：资料来源与核验表

```markdown
# 《××》资料来源与核验表

核验日期：YYYY年M月D日

| 页码 | 页面标题 | 核验事项 | 来源与链接 | 年份/日期 | 口径与备注 |
|---|---|---|---|---|---|
| 第3页 | 认识××类，先记住这5个判断 | 学历门槛与就业判断 | [来源名称](链接) | 2026 | 全国性资料与代表性岗位样本综合判断 |
| 第6页 | ××类包含哪些细分专业 | 专业名称、代码与目录属性 | [教育部本科专业目录](链接) | 2026 | 以当年目录为准 |
```

来源表服务于研发核验，不交给PPT生成AI渲染。一个页面有多个关键事实时可拆成多行。没有新增事实的目录页、过渡页和总结页注明“无新增事实，依据前述页面”。

## 一致性规则

- PPT稿与逐字稿页数一致。
- 页码一致。
- 标题逐字一致。
- PPT中的要点、表格维度和数据都在逐字稿中按原顺序解释。
- 逐字稿可以增加解释、类比和场景，不得增加新的页面主题。
- 逐字稿不得提前详细讲下一页。
- 过渡页逐字稿只承接上一模块并引出当前模块，通常两三句话。
- 封面、目录也有对应讲解，但保持简短。
- 最后一页不写下一页过渡，改为课程收束语。
- 引用和核验备注只进入资料来源与核验表。

## 自动校对

| 检查项 | 结果 |
|---|---|
| PPT稿与逐字稿页数相同 | 通过/修正 |
| 每一页标题完全相同 | 通过/修正 |
| PPT每项内容均有同序讲解 | 通过/修正 |
| PPT稿没有模板标签和制作指令 | 通过/修正 |
| 逐字稿没有PPT要点复印区 | 通过/修正 |
| 没有跨页重复展开 | 通过/修正 |
| 每个目录模块都有对应过渡页 | 通过/修正 |
| 没有仅换版式的全景图或视觉汇总页 | 通过/修正 |
| 关键事实已进入独立核验表 | 通过/修正 |

检查表用于内部校对，除非用户要求，不写入最终文件。
