# 格知通俗逐字稿规范

## 表达目标

把专业研究转化为教师可以直接照读、学生和家长能够听懂的完整口语。

遵循：

- 先结论，后解释。
- 从普通毕业生的现实出口倒推专业价值。
- 区分行业热度与专业就业，区分头部个案与多数人的路径。
- 重视学历门槛、院校平台、城市、项目实习和家庭试错成本。
- 用专业对比、现实场景和生活类比解释抽象概念。
- 明确说出优势、限制和风险，不用“前景广阔”代替分析。

## 每页逐字稿结构

每页以 `# 第X页｜与PPT完全相同的标题` 开始，随后直接写可照读的讲解。不要输出“对应的PPT要点”“逐字讲解”“使用说明”等模板标签，也不要把PPT文字先复制一遍。

按PPT内容原顺序自然组织：

1. **标题导入**：一句话说明本页解决什么问题。
2. **结论先行**：直接说本页判断。
3. **逐点讲解**：PPT有几个要点，就按相同顺序讲清几个要点；可使用“第一、第二”，也可用自然段衔接。
4. **现实解释**：只使用一个最必要的对比、场景或类比；结论已经清楚时可不展开。
5. **风险落点**：指出这一页对专业选择或规划师讲解意味着什么。
6. **本页小结与过渡**：通常合并成一句15—35字的桥接语，最多不超过45字；同时收住本页并引出下一页。

## 语言要求

- 使用完整口语句子，让教师可以直接照读。
- 每句尽量短，一句话只表达一个判断。
- 优先使用“先看什么、再看什么、最后看什么”的顺序。
- 抽象术语首次出现时立即用大白话解释。
- 使用“你看到的是……真正决定的是……”“不要把A和B混在一起”等对比句式。
- 允许适量反问，但反问后必须给答案。
- 允许说“对口岗位较少”“更建议读研”，但必须给依据和适用范围。
- 避免学术腔、报告腔、广告腔和机械照读表格。

默认使用精简版逐字稿：

- 普通内容页建议150—260字。
- 复杂表格页原则上不超过320字，只解释关键差异，不逐格朗读。
- 封面、目录和过渡页建议60—120字。
- 同一判断只完整解释一次；后续页面需要承接时，用一句话点到为止。
- 每页最多保留一个必要案例或类比，能够直接说清时不强行举例。
- 删除暖场套话、同义复述、重复小结和提前展开下一页的内容。
- 页间衔接必须保留，但只占一句话；根据内容关系使用因果、递进、转折或设问，不机械重复“接下来我们来看”。
- 衔接放在上一页结尾或下一页开头之一，不在两处重复表达。
- 用户明确要求“详细逐字稿”“长讲版”时，才可在事实边界内适当扩展。

字数是控制冗余的参考，不是硬性凑字目标。必须优先保证PPT要点完整覆盖、顺序一致和教师可直接照读。

## 对应示例

PPT页面内容：

1. 数学是基础
2. 算法是核心
3. 编程是实现工具

逐字稿直接讲解并保持同序：

> 第一，数学是基础。模型为什么能识别图片，背后靠的不是感觉，而是线性代数、概率统计和优化方法。
>
> 第二，算法是核心。专业真正研究的是，怎么让计算机从数据中发现规律。
>
> 第三，编程是实现工具。算法想得再好，最后也要通过代码把它做出来。

不要在逐字稿页面里再次粘贴这三个PPT要点。不要先讲第三点再回头解释第一点，也不要增加一个PPT没有承载的新结论。

## 表达边界

- 不模仿或冒充任何具体人物。
- 不使用粗俗、羞辱和攻击性语言。
- 不为制造冲突使用过度极端措辞。
- 不编就业率、薪资、岗位数和院校结论。
- 不把单一学校的培养方案当成全国统一情况。
- 不连续堆砌口头禅。

## 事实与语气

大白话负责降低理解门槛，不能降低事实标准：

- 有权威数据：说清年份、口径和它说明什么。
- 只有趋势证据：使用“整体更偏向”“通常更看重”等准确措辞。
- 缺少可靠资料：直接说明需要结合当期数据复核。
- 存在院校差异：明确说明不同学校的培养侧重可能不同。
