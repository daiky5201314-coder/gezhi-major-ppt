# 格知教育专业篇课程研发 Skill

用于格知教育“导师计划—专业篇”的专业咨询、专业大类课程研发和单专业课程研发。

## 什么时候触发

- “这个专业怎么样”“好不好就业”等普通咨询：直接回答，不生成文件。
- “整理××类资料”“生成PPT内容稿”“制作逐字稿”等明确课程研发请求：生成完整课程文件。
- 无法判断是专业大类还是单个专业时：先确认专业层级。

## 默认生成的文件

1. `<主题>-PPT内容稿.md`
2. `<主题>-逐字讲解稿.md`
3. `<主题>-资料来源与核验表.md`

PPT内容稿只包含可直接显示在页面上的最终文字，可直接交给PPT生成AI。逐字稿与PPT逐页对应，只包含老师可以照读的口语。研究链接、年份、口径与复核提醒统一进入第三个文件。

专业类课程生成后，默认把 Markdown 成品上传至飞书云盘“专业库资料制作过程文件夹”下对应的专业类目录，并返回本地和飞书链接。新文件共用 `V1.0`、`V2.0` 等版本号，保留旧版；单个专业课程暂时只保存在本地。飞书账号、目录定位和异常处理见 [`references/feishu-delivery.md`](references/feishu-delivery.md)。

## PPT内容稿格式

```markdown
# 第1页｜页面标题

本页直接上屏的文字、列表或表格。

---

# 第2页｜页面标题

本页直接上屏的文字、列表或表格。
```

不要在PPT内容稿中加入“本页核心结论”“PPT展示内容”“建议呈现形式”“资料依据”等固定模板标签，也不要加入配色、构图或动画指令。

专业大类课程要求：

- 封面后设置目录。
- 进入每个目录一级模块前设置独立过渡页。
- 目录使用简洁模块名，过渡页使用有判断、有对比的成品标题。
- 过渡页标题保持正式、凝练和克制，不使用内部策划语言或标题党表达。
- 包含过渡页在内不超过45页，页数是上限，不是必须达到的数量。
- 同一专业名单只完整出现一次，不设置仅换版式的“全景图”或视觉汇总页。
- 内容可以合并时优先合并，但行业、岗位、本科就业和考研等不同问题仍要保持清晰边界。

单专业课程包含3张模块过渡页，总页数仍不得超过15页。

## 课程结构

- 专业大类课程使用 `references/large-category-template.md`。
- 单专业课程使用 `references/single-major-template.md`，包括封面和目录在内不超过15页。
- Markdown交付格式使用 `references/markdown-output.md`。
- 逐字稿表达使用 `references/gezhi-plain-language-script.md`。
- 资料研究与事实核验使用 `references/research.md`。

这些模板只用于内部规划，不能原样复制到最终PPT内容稿。

## 使用示例

> 请使用 gezhi-major-ppt，整理计算机类资料，生成PPT直接上屏内容稿、逐字讲解稿和资料来源与核验表。

> 请使用 gezhi-major-ppt，整理人工智能专业课程资料。人工智能指单个本科专业，总页数控制在15页以内。

## 事实边界

- 优先使用教育部、政府部门、高校官网、培养方案和官方就业资料。
- 不编造就业率、薪资、岗位数量和院校结论。
- 不用头部院校或顶尖毕业生代表多数学生。
- 院校、专业目录、岗位与政策信息在正式使用前按最新年份复核。
